Check this machine for kersh. Exits 1 when a required piece is missing.

Reports the harnesses, the host and session server, the kersh-host unit, gaff and its hooks, the guard for each harness and mode, and the eng.rip tools, against the login environment. Required: kersh and gaff on the login PATH, gaff's hooks for each harness found, and a running host or session server of this kersh's version.

Usage: kersh doctor [OPTIONS]

Options:
      --json
          Print JSON, one object per line

  -h, --help
          Print help (see a summary with '-h')
